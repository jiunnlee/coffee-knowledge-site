# 圖片維護

所有生成影象為 AI 教學示意，不能代表實際商品、裝置、產地或歷史影像。商品與裝置應由業主提供實拍，並確認可公開使用。

`assets/masters/` 保留生成母檔；`assets/manifest.json` 記錄提示詞、日期、用途、替代文字與尺寸。`public/images/` 是瀏覽器使用的 WebP。文章 frontmatter 的 coverImage 使用 `/images/name.webp`；建置會加入部署子路徑，不需自行寫 repo 名稱。

更換圖片應同時更新 alt 與來源紀錄。照片避免生成文字與商標；封面主體保留裁切安全區。技術轉碼／尺寸調整不等於提高原生細節，須保留原始尺寸與轉換尺寸的紀錄。

執行 build/test 後實際檢查手機與桌面裁切，避免主體被切掉。母檔不直接供網頁下載，公開網站僅使用壓縮圖檔。
