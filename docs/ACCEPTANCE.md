# 驗收報告

本次依 V1.0 規格建置純靜態網站；自訂 Node.js 建置器讀取 Markdown/YAML 與 JSON，產出所有文章完整 HTML，無資料庫與伺服器依賴。GitHub Pages 子路徑統一為 `/coffee-knowledge-site/`。

## 內容與介面

74 篇實質繁體中文文章：知識15、故事12、配方15、沖煮12、產地12、品鑑8。包含導言、分節、日期、封面、麵包屑、相關閱讀、分享；15篇配方含公克／毫升份量、器具、難度、時間、步驟、替代材料與注意事項。資料以官方／研究來源為主，歷史傳說明示。

首頁十個主要編輯模組與額外探索工具。分類、烘焙、豆款、代烘、關於、搜尋、聯絡、隱私、宣告及404均有完整頁面。共有89個可索引頁面與404。

每日知識35則、當地日期固定且處理跨日；推薦不重複上一項；規則式偏好測驗可重做；15g×16=240g 並檢查非法輸入；全文搜尋涵蓋標題／摘要／標籤／本文及中文、標籤與零結果提示。基本文章不依賴JavaScript。

54個不同AI影象資產，保留母檔與提示詞／日期／用途／alt／尺寸／來源紀錄，提供WebP與400/800尺寸變體。全部明示教學示意。主視覺交付2048×1152，由工具原生1672×941轉換放大，未增加原生細節；見 IMAGE-QA.md。真商品及裝置均無虛構照片。

兩首使用者MP3曲目，預設關閉與preload none，點選才播，按1→2→1依序輪播；無重疊、快速切換、關閉、背景持續、站內導航不中斷與真正離站停止生命週期均處理，播放阻擋或缺檔有提示。

## 自動與實際驗證

- production build 與內容／資產／子路徑連結檢查透過：74篇、54圖、35則知識、4269個內部連結／資產引用。
- Windows 已安裝 Google Chrome 的隔離無頭測試程式：360、390、768、1440畫素，無橫向溢位與圖片缺檔。
- 驗證導覽、文章詳頁、搜尋、標籤、返回／前進、重複操作、測驗、比例、推薦、分享與停用JavaScript閱讀，無JS例外。
- 使用Asia/Taipei與America/New_York時區驗證每日知識重整穩定與午夜切換。
- 音樂以真實播放與seek至曲尾檢查自然ended輪播，另測十次快速切換、關閉後ended、背景持續／站內連續／真正離站、404與瀏覽器阻擋。
- 視覺檢閱首頁與文章、配方及各類影像；依結果修正配方材料、器具、手機標題換行與音樂開關。

以上工具報告與截圖保留本機 test-results；最終釋出commit、CI結果與公開網址載入驗證由交付紀錄提供。不是以push成功替代部署成功。

## 待設定與限制

店家資訊已依使用者要求留待日後：品牌、聯絡、裝置實拍、商品批次、服務條件等集中設定，不阻塞知識網站閱讀，也沒有假洽詢連結。咖啡誌為暫用編輯名稱。

配方為可操作的教學起始配方，未聲稱經店家實測或實際販售。影象示意不代表真實產地／歷史紀錄；母檔主視覺原生解析度限制如上。SEO資料完整但不保證搜尋流量。無分析追蹤、會員、金流、SQL或網站AI服務。

## 2026-10-12 音樂連續播放修正

原始版本使用整頁導航且把背景分頁視為停止，造成站內切頁斷音。本次加入持久導航與互動掛載清理，讓頁首audio留在同一document；站內文章、分類、配方、搜尋、首頁與歷史導航保持audio identity與currentTime連續，兩首自然ended依序循環。主動關閉及真正離站才停止。回歸測試另驗證手機、快速切換、播放失敗與無JS閱讀。此修正依使用者本次例外批准只發布一次。
